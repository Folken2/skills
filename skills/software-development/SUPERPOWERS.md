This theme uses superpowers (https://github.com/obra/superpowers) as its core development methodology. Superpowers by Jesse Vincent / Prime Radiant provides engineered workflows for brainstorming, specing, TDD, systematic debugging, code review, planning, git worktrees, and subagent-driven development. Attributed under the MIT License.

Install: `/plugin install superpowers@claude-plugins-official` (Claude Code) or follow the per-harness install steps in the superpowers repo (Cursor, Codex, Gemini CLI, Hermes, Pi, etc.).

Our skills complement superpowers: bug-triage hands off to systematic-debugging on complex bugs; feature-shaping feeds writing-plans; second-order-impact-analysis complements verification-before-completion.
